041 - مكتب الإطعام المدرسي - التسيير اليومي

المرجع: المرسوم 18-03، التعليمة الوزارية المشتركة للإطعام 2021
التنظيم:
  • مسير مطعم: مسير مطاعم مدرسية + عمال مطبخ + عون نظافة
  • لكل مطعم: سجل استلام مواد، سجل استهلاك يومي، سجل وجبات، بطاقة مخزون
  • المخزون: دخول بون استلام، خروج بون استهلاك، جرد شهري
الوجبة النموذجية:
اليوموجبة مقترحة
السبتأرز + دجاج + سلطة + فاكهة
الأحدمعكرونة + بيض + جبن + خضر
الاثنينكسكسي + خضر + لحم + لبن
الثلاثاءلوبيا + سلطة + فاكهة
الأربعاءشربة + سلطة + جبن + فاكهة
التموين:
  • صفقة طلبات: تموين مواد غذائية حسب احتياجات سنة، دفتر شروط، التزام، توصيل أسبوعي
  • المراقبة: طبيب حفظ الصحة، مدير مدرسة، مسير، يومية
  • النظافة: مطبخ، أواني، عمال شهادات صحية
