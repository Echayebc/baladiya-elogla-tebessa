### 2. رئيس المجلس الشعبي البلدي
ينتخب حسب المادة 65 الجديدة:
- إذا قائمة لها أغلبية مطلقة (>10 مقاعد) هي من ترشح
- إذا لا توجد أغلبية، القائمتان الحائزتان 35% (7 مقاعد) على الأقل ترشحان
- إذا لا أحد بلغ 35%، كل القوائم ترشح
- الانتخاب بالأغلبية المطلقة داخل المجلس

مهامه: آمر بالصرف، ضابط حالة مدنية، ضابط شرطة قضائية، ينفذ المداولات
